"FAQ" — නිති අසන ප්‍රශ්න

අහන්න බොත්තම වැඩ නොකරන්නේ ඇයි?

මුලින්ම අපි Dilu සිංහල හඬ ගොනුවක් භාවිතා කරමු. ඒක අසාර්ථක නම් බ්‍රවුසර හඬට යයි. සමහර බ්‍රවුසර / දුරකථනවල සිංහල හඬ (si-LK) නැත. Chrome හෝ Edge උත්සාහ කරන්න. හඬ නැතත් පෙළ කියවන්න පුළුවන් — කිසිම ප්‍රශ්නයක් නැහැ.

"GitHub" මුරපදය අමතක උනොත්?

github.com එකේ “Forgot "password"” ඔබන්න. ඊමේල් එකට ලින්ක් එකක් එනවා. අලුත් මුරපදය ආරක්ෂිතව ලියා තබන්න.

මගේ පිටුව ලෝකයට පේනවද?

Public repository + "GitHub Pages" = ඔව්, ලින්ක් එක තියෙන කෙනෙකුට පේනවා. පවුලේ රහස් දේවල් public එකට දාන්න එපා.

"AI" ට සිංහලෙන් කතා කරන්න පුළුවන්ද?

ඔව්. "ChatGPT", "Claude", "Grok" වගේ මෙවලම් සිංහල තේරුම් ගනී. සරල වාක්‍යවලින් කියන්න.

මිතුරෙකුට මේ අඩවිය පිටපත් කරන්නේ කොහොමද?

"GitHub" එකේ Fork බොත්තම ඔබන්න, නැත්නම් Code → Download ZIP. ඔවුන්ගේ ගිණුමේ "Pages" සක්‍රිය කරන්න. "README" එකේ විස්තර තියෙනවා.

කේතය දන්නේ නැත්නම් මම පුළුවන්ද?

ඔව්! මේ මාර්ගයේ අරමුණම ඒකයි. "AI" උදව් කරනවා; ඔබ අදහස් කියනවා. ජේ සහ මිතුරෝ අසලින් ඉන්නවා.
