ආයුබෝවන්! මම ජේ.

මම මගේ අම්මා, තාත්තා, සහ යාළුවන්ට ඉගැන්වීමට මේ වෙබ් අඩවිය හදුවෙමි. GitHub කියන්නේ අන්තර්ජාලයේ තවත් පරිගණකවලට දොරටුවක්. AI (ChatGPT, Claude, Grok) කියන්නේ උදව් කරන මිතුරෙක් — ඔබට අවශ්‍ය වැඩසටහන් හදන්න උදව් වෙනවා.

පටන් ගමු → මුලින් මොකද්ද කියලා දැනගමු

ඇයි මේක වැදගත්ද?

පරිගණකයක් හෝ දුරකථනයක් තියෙනවා නම්, ඔබටත් කුඩා වෙබ් අඩවියක්, පවුලේ පිටුවක්, හෝ ගමේ ප්‍රවෘත්ති පුවරුවක් හදන්න පුළුවන්. කේතය මතක තියාගන්න ඕන නැහැ — AI මිතුරාට සිංහලෙන් කියන්න, GitHub එකට දාන්න, දුරකථනෙන් විවෘත කරන්න.

මෙය කුමක්ද?

පරිගණකය, අන්තර්ජාලය, GitHub, AI — සරල උපමාවලින්.

පියවරෙන් පියවර

ගිණුමක් සාදා, AI එක්ක වෙබ් අඩවියක් හදා, දුරකථනෙන් බලන්න.

උදාහරණ — ගම්පහ

ගම්පහ ප්‍රවෘත්ති හා කාලගුණය ආදර්ශ පිටුව.

කුඩා උපදෙස්

සෑම කොටසකම අහන්න බොත්තම තියෙනවා. ඔබන්න — බ්‍රවුසරය සිංහලෙන් කියවයි (සහාය තියෙන උපාංගවල). ඉක්මන් නොවන්න. එක පියවරක් එකවර.

ජේගේ AI සිංහල මාර්ගෝපදේශය — මිතුරන්ට සහ පවුලට නොමිලේ.
