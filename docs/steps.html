පියවරෙන් පියවර

එක වේලාවක එක පියවරක්. ඉක්මන් නොවන්න. අමාරු නම් ජේට හෝ මිතුරෙකුට අහන්න.

මාර්ගය

  1. "GitHub" ගිණුමක් සාදන්න

    github.com/signup වෙත යන්න. ඊමේල් එකක් සහ මුරපදයක් ("password" (පාස්-වර්ඩ්)) තෝරන්න. මුරපදය කඩදාසියක ආරක්ෂිතව ලියා තබන්න.

  2. "ChatGPT" / "Claude" / "Grok" විවෘත කරන්න

    ඔබට පහසු "AI" එකක් තෝරන්න. "ChatGPT" (chat.openai.com), "Claude" (claude.ai), හෝ "Grok" (grok.com / x.com). ගිණුමක් හදා සිංහලෙන් කතා කරන්න.

  3. "GitHub" සම්බන්ධ කරන්න — ප්‍රවේශමෙන්

    සමහර "AI" මෙවලම්වල "GitHub" සම්බන්ධ කරන්න පුළුවන්. අවසර දෙන්නේ ඔබ තේරුම් ගත් දේට පමණයි. මුරපද හෝ රහස් යතුරු කිසිවිටෙකත් පණිවිඩයකට ටයිප් කරන්න එපා.

  4. "AI" ට කුඩා වෙබ් අඩවියක් හදන්න කියන්න

    උදාහරණය: “මට සිංහලෙන් කුඩා "HTML" පිටුවක් හදන්න — මගේ ගමේ නම සහ ආයුබෝවන් කියලා.” "AI" දෙන කේතය පිටපත් කරගන්න.

  5. "GitHub" එකේ ගොනු බලන්න

    නව repository (ගබඩාව) එකක් හදා, index.html වගේ ගොනු එකතු කරන්න. ගොනු ලැයිස්තුවේ ඔබේ පිටුව පේනවා නම් හොඳයි!

  6. "GitHub Pages" (ගිට්-හබ් පේජස්) සක්‍රිය කරන්න

    Settings → "Pages" → Deploy from branch → main → folder /docs හෝ root. විනාඩි කිහිපයකින් ඔබේ අඩවියට ලින්ක් එකක් ලැබෙනවා.

  7. දුරකථනයෙන් විවෘත කරන්න

    ලින්ක් එක WhatsApp එකෙන් ඔබටම යවලා, දුරකථනෙන් ඔබලා බලන්න. “මගේම වෙබ් අඩවිය!” කියලා දැනෙයි.

  8. (විකල්ප) පවුලට මුරපදයක්

    පොදු (public) පිටු පවුලේ රහස් දේවල් සඳහා නුසුදුසුයි. පුද්ගලික දේවල්ට private repo හෝ වෙනම මුරපද ක්‍රමයක් ගැන "AI" ගෙන් අහන්න.

ආරක්ෂාව — කරුණාකර කියවන්න

  • රහස් (මුරපද / "password", "API" (ඒ-පී-අයි) keys, බැංකු තොරතුරු) කිසිවිටෙකත් "AI" චැට් එකට හෝ public "GitHub" එකට දාන්න එපා.
  • Public = ලෝකයට පේනවා. Private = ඔබට සහ ඔබ අරමුණු කළ අයට පමණයි.
  • කෙනෙකුට මුදල් ඉල්ලන, හදිසි “ගිණුම අවුල්” පණිවිඩ විශ්වාස නොකරන්න — ජේගෙන් හෝ පවුලෙන් අහන්න.

උදාහරණය බලන්න → ප්‍රශ්න තියෙනවද?

ජේගේ "AI" සිංහල මාර්ගෝපදේශය — මිතුරන්ට සහ පවුලට නොමිලේ.
