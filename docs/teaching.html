ජේගේ ඉගැන්වීමේ සටහන්

මිතුරන්ට උගන්වන විට භාවිතා කරන්න. ඉවසීම ප්‍රධානයි.

න්‍යාය පත්‍රය (Agenda)

  1. ආචාර + බිය ඉවත් කිරීම (10 විනාඩි)

    “වැරැද්දක් උනොත් කිසිම ප්‍රශ්නයක් නැහැ. අපි එකට ඉගෙන ගමු.” මුල් පිටුවේ අහන්න බොත්තම පෙන්වන්න.

  2. උපමා (15 විනාඩි)

    “මෙය කුමක්ද?” පිටුව — GitHub = දොරටුව, AI = මිතුරා. එක උපමාවක් එකවර.

  3. ගිණුම් (20–30 විනාඩි)

    GitHub signup. මුරපදය කඩදාසියක. අවශ්‍ය නම් ඊමේල් තහවුරු කිරීමේදී උදව් වෙන්න.

  4. AI සමග කුඩා ජයග්‍රහණය (20 විනාඩි)

    සරල “ආයුබෝවන්” පිටුවක් AI ගෙන් ඉල්ලන්න. කේතය පෙන්වලා, ගොනුවක් සේව් කරන ආකාරය.

  5. Pages + දුරකථනය (15 විනාඩි)

    Pages සක්‍රිය කර, ලින්ක් එක දුරකථනෙන් විවෘත කර, සැමෝත්සවයක්!

නැවතී යන තැන් (Stuck points)

  • ඊමේල් තහවුරු කිරීම / spam ෆෝල්ඩරය
  • මුරපද අමතක වීම — කලින් කඩදාසියක ලියන්න
  • English UI — සෙමෙන් පෙන්වන්න; සිංහල පෙළ අසල තියන්න
  • Pages ප්‍රමාද වීම — විනාඩි 2–10 ක් ඉන්න කියන්න
  • TTS සිංහල හඬ නැති උපාංග — පෙළ කියවන්න; Chrome උත්සාහ කරන්න

ඉවසීමේ ලැයිස්තුව

  • ✓ කටහඬ සන්සුන්ව, උසස් නොකර
  • ✓ එකවර බොත්තම් දෙකක් පෙන්වන්න එපා
  • ✓ ඔවුන්ගේ අතින්ම ක්ලික් කරන්න දෙන්න
  • ✓ වැරැද්දක් = ඉගෙනීමේ කොටසක් කියලා කියන්න
  • ✓ විවේකයක් දෙන්න — තේ කෝප්පයක්
  • ✓ අවසානයේ ඔවුන් කළ දේ පැහැදිලිව ප්‍රශංසා කරන්න
